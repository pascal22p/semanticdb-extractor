# SemanticDB Extractor

A Scala 3 tool for extracting and inspecting information from [SemanticDB](https://scalameta.org/docs/semanticdb/specification.html) files.

## Overview

This project provides utilities to read SemanticDB files generated by the Scala compiler and extract structured information about classes, traits, objects, and their methods.

## Features

- **Architecture Generator**: Scans a directory for `.semanticdb` files and prints a summary of classes, their parameters, and methods.
- **SemanticDB Inspector**: A low-level tool to inspect the raw contents of a specific `.semanticdb` file.

## Prerequisites

- [sbt](https://www.scala-sbt.org/) (version 1.12.5 or higher)
- [Java SDK](https://www.oracle.com/java/technologies/downloads/) (version 8 or higher)

## Usage

### Building the project

```bash
sbt compile
```

### Running the Architecture Generator

The `ArchitectureGenerator` scans a directory for SemanticDB files and outputs the structure of the found classes. You can run it using the default `sbt run` command:

```bash
sbt "run <path-to-semanticdb-directory>"
```

### Running the SemanticDB Inspector

The `InspectSemanticDb` tool prints the raw symbol information from a single `.semanticdb` file.

```bash
sbt "runMain InspectSemanticDb <path-to-file>.semanticdb"
```
