# SemanticDB Extractor

A Scala 3 tool for extracting and inspecting information from [SemanticDB](https://scalameta.org/docs/semanticdb/specification.html) files.

## Overview

This project provides utilities to read SemanticDB files generated by the Scala compiler and extract structured information about classes, traits, objects, and their methods.
